# Farmalengke

> A global effort to help improve farming efficiency.

Farmalengke is an open project for building tools, data, and shared knowledge that
make farming more efficient — for smallholder growers and large operations alike.

## Status

**Pre-alpha.** The repository has just been initialized. There is no application
code yet; what exists today is the project scaffolding, contribution process, and
the documentation that will shape what gets built.

## Goals

- **Practical over theoretical.** Ship things a working farmer can actually use.
- **Locally relevant, globally useful.** Crops, climates, and units differ by
  region; the project should not assume one context is the default.
- **Open data and open methods.** Recommendations should be traceable to a source.
- **Low barrier to access.** Assume intermittent connectivity and modest hardware.

## Getting started

There is nothing to build or run yet. To follow along or help shape the direction:

1. Read [`docs/roadmap.md`](docs/roadmap.md) for the current thinking.
2. Read [`CONTRIBUTING.md`](CONTRIBUTING.md) for how to propose changes.
3. Open an issue describing a farming problem worth solving, or comment on an
   existing one.

## Contributing

Contributions are welcome — including from people who do not write code. Field
experience, agronomic review, translations, and documentation are as valuable
here as commits. See [`CONTRIBUTING.md`](CONTRIBUTING.md).
